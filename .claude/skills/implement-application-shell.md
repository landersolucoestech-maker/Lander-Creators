# implement-application-shell

1. Audit existing user-facing routes and navigation.
2. Reuse current session, Workspace context and authorization services.
3. Build one shared authenticated shell with semantic navigation and main landmarks.
4. Keep unauthenticated routes outside the shell.
5. Make navigation capability-aware without role-name checks.
6. Validate direct-route authorization, mobile drawer, keyboard focus and accessibility.
7. Do not add new business domains.
