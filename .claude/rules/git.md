# git

- Work exclusively on `main`.
- Never create, use, update, synchronize or push another branch.
- Treat every non-`main` branch as a policy violation to be removed.
- Do not use pull-request/topic-branch workflow for LANDER CREATORS.
- Do not force push or rewrite history unless explicitly authorized for repository recovery.
- Validate repository identity, current branch and remote HEAD before every write.
