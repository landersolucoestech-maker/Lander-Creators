# pre-task

Before work:
1. Verify repository identity is `landersolucoestech-maker/Lander-Creators`.
2. Verify the current/target branch is exactly `main`.
3. Stop if the requested operation would create, use, update, synchronize or push any non-`main` branch.
4. Classify the task stage, lock scope and identify required validation.
5. Report any non-`main` branch as a repository-policy violation to be removed.
